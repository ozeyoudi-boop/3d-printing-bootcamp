The steps below use Fusion terminology, but the same loop exists in every CAD program.

The CAD loop

  1. Sketch a 2D profile on a plane and add dimensions and constraints so it is fully defined.
  2. Extrude (or revolve) it into a solid; choose join, cut or new body.
  3. Modify: fillet/chamfer edges, shell, add holes.
  4. Parameters: name your key sizes (width, wall, cable_d) and use them in sketches so changing one number updates the model.

Worked example: parametric cable clip

A clip that sticks to a desk edge and holds a 6 mm cable. Create these parameters first (Modify → Change Parameters → User Parameters):

NameValueMeaning
width30 mmClip width
wall2.4 mmWall thickness (≈ 6 loops at 0.42)
cable_d6 mmCable diameter
clear0.4 mmExtra gap so the cable slides in
  1. Sketch on the XY plane: a centre circle of diameter cable_d + clear.
  2. Draw an outer circle of diameter cable_d + clear + 2*wall.
  3. Extrude the ring width.
  4. Sketch a slot on the top for the cable to snap in: a rectangle narrower than the cable (cable_d*0.8), cut through the ring.
  5. Fillet the slot's edges 0.6 mm so the cable doesn't catch.
  6. Add a flat base: sketch a rectangle under the ring, extrude to join. A flat base prints without supports.
  7. Export: right-click the body in the browser → Save as Mesh → 3MF (or STL), millimetres, refinement “High”.

Now change cable_d to 4 and watch everything update. That is parametric design.

Tinkercad version: drop a tube, set the hole size to the cable diameter + 0.4, add a box under it as a base, subtract a small box from the top as the slot, then Export → STL.

Exercises

EXERCISE 1

Resize in one step

Change cable_d to 4 mm and width to 20 mm in your clip. What breaks?

Hint
If something breaks, a dimension was typed as a number instead of using a parameter.
Show solution
Nothing should break. Anything that doesn't update still contains a hard-coded number; replace it with the parameter name.
EXERCISE 2

Add a mounting hole

Add a 3.4 mm hole through the base for an M3 screw, centred 6 mm from the edge. Make 3.4 a parameter called m3_hole.

Hint
Sketch on the top face of the base, circle, dimension, then extrude-cut through all.
Show solution
3.4 mm gives clearance around an M3 screw (nominal 3.0) after the printer's slight shrinkage of holes. See module 4.
EXERCISE 3

Rebuild in Tinkercad

Make the same clip using only a tube, boxes and the Hole tool. Compare how long it took and what you couldn't set precisely.

Hint
Tinkercad dimensions are typed in the shape's handles.
Show solution
Tinkercad is faster for one-offs, parametric CAD is faster for the second and third version. Both are valid; choose by how often you'll change the design.

Checkpoint quiz

What makes a CAD model 'parametric'?

Parameters let you edit one number and rebuild the whole model.

Why design the clip with a flat base?

A flat face on the plate gives adhesion and removes the need for supports.

Which export is best for a one-colour print you'll slice immediately?

Slicers read mesh formats; the original CAD file stays your master.

You type 6 into a sketch dimension instead of using cable_d. Result?

Hard-coded numbers don't update when the parameter changes.
