Edit, repair and remix models

Which route for which edit?

You haveYou wantRoute
STEP or CAD fileChange dimensionsOpen in CAD, edit parameters or features
STL/3MF meshCut it, add a block, add text, scaleBambu Studio (cut, add shapes, text emboss, boolean)
Broken or messy meshRepair holes, merge, decimateBlender (3D-Print Toolbox) or Bambu Studio's import repair
MeshExact dimensional change (e.g. move a hole)Rebuild in CAD using the mesh as reference
Rule: edit as upstream as possible. Fixing the CAD source beats fixing the mesh; fixing the mesh beats fixing it in the slicer.

What 'broken' means

  • Non-manifold edges: an edge shared by more or fewer than two faces. The slicer can't tell inside from outside.
  • Holes: missing triangles in the surface.
  • Flipped normals: faces pointing inward.
  • Intersecting / duplicate geometry: overlapping shells or doubled vertices.

Bambu Studio flags many of these with a warning icon on import and attempts a repair. Check the preview anyway: missing walls or odd gaps in the sliced layers mean the repair didn't fix it.

Worked example: repair in Blender

  1. Import the STL. Set Scene Properties → Units → Metric, Unit Scale 0.001, Length Millimetres so the dimensions you see are real.
  2. Tab into Edit Mode. Select → Select All by Trait → Non Manifold. Whatever highlights is a problem area.
  3. Merge near-duplicate vertices, then recalculate normals outward, then fill holes (select the boundary loop, press F).
  4. Enable the 3D-Print Toolbox extension and run Check All: it lists non-manifold edges, intersections, thin walls and overhangs.
  5. Export STL or 3MF in millimetres.

The same steps by script (run in Blender's Scripting tab with the object active):

import bpy
bpy.ops.object.mode_set(mode='EDIT')
bpy.ops.mesh.select_all(action='SELECT')
bpy.ops.mesh.remove_doubles(threshold=0.0001)       # merge near-duplicate vertices
bpy.ops.mesh.normals_make_consistent(inside=False)  # point normals outward
bpy.ops.mesh.select_all(action='DESELECT')
bpy.ops.mesh.select_non_manifold()                   # highlights what is still broken

Remixing from MakerWorld

  • Read the model's licence. Some allow remixing with credit; some forbid derivatives or commercial use.
  • Prefer downloading the project 3MF: it carries the author's tested orientation, colours and profile.
  • Quick modifications (cut a piece off, add a hole, emboss your name) can be done in Bambu Studio without CAD.
  • Credit the original author when you share a remix.
