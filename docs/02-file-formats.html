File formats and conversion

By the end you can…

  • Choose between STEP, STL, 3MF and OBJ for any situation
  • Convert between mesh formats with a short script or an app
  • Diagnose a wrong-size import (unit mismatch)

Two families: solid models and meshes

Solid (B-rep) models store exact surfaces — a cylinder is a cylinder. Meshes store thousands of triangles approximating the surface. CAD programs work in solids; slicers work in meshes. Going solid → mesh is easy and safe. Going mesh → solid is lossy and often impossible, so always keep your original CAD file.

FormatTypeKeepsUse it for
.step / .stpSolidExact geometry, editable in any CADSharing a part someone else will edit
.stlMeshTriangles only. No units, colour or settingsUniversal download format; fine for one-colour prints
.3mfMesh + packageUnits, multiple objects, colours, and slicer settingsBest format for Bambu Studio; Bambu's project files are 3MF
.objMeshTriangles/polygons, colours and textures through an .mtl fileScans and Blender workflows
.f3d / .blend / .FCStdNativeEverything that app knowsYour working source files
STL has no units. The slicer assumes millimetres. A model exported in inches arrives 25.4× too small. Always confirm size after import.

Conversion paths that work

  • CAD → 3MF or STL: use the app's export / “save as mesh” command. Pick a fine refinement setting so curves aren't visibly faceted.
  • STEP → slicer: Bambu Studio can import STEP directly and turns it into a mesh for you.
  • OBJ ↔ STL ↔ 3MF: any mesh app, or the script below.
  • Mesh → STEP: avoid. Use the mesh only as reference and rebuild it in CAD if you need dimensional edits.

Worked example: convert and sanity-check in Python

This uses the trimesh library (pip install trimesh numpy).

import trimesh

mesh = trimesh.load("part.obj", force="mesh")   # load as one mesh
print("size (x,y,z):", mesh.extents)             # compare with what you expect, in mm
print("watertight:", mesh.is_watertight)         # True = closed, printable solid
print("volume mm3:", mesh.volume if mesh.is_watertight else "n/a")

mesh.export("part.stl")                          # format chosen from the extension

If a part you designed as 100 mm wide reports 3.94 in extents, it was exported in inches. Multiply by 25.4 — in the script with mesh.apply_scale(25.4) or in the slicer by scaling 2540%.

Exercises

EXERCISE 1

Pick the format

Choose a format for each: (a) a bracket a friend will modify in their CAD; (b) a two-colour keychain you'll slice yourself; (c) a figurine you're uploading for people to print in one colour; (d) a coloured scan from your phone.

Hint
Ask: does anyone need to edit it? Does colour matter?
Show solution
(a) STEP. (b) 3MF — keeps colours and objects. (c) STL (universal) or 3MF. (d) OBJ with its .mtl/texture, or 3MF.
EXERCISE 2

Diagnose the size

You export a 2-inch cube from CAD set to inches and import it into Bambu Studio. It appears 2 mm wide. Why, and what fixes it?

Hint
STL stores the number 2, not the unit.
Show solution
The slicer reads 2 as 2 mm. Fix by exporting in millimetres (preferred) or by scaling the model by 25.4× (2540%) to get 50.8 mm.
EXERCISE 3

Run the check

Run the Python example on a downloaded STL (change the filename). Report extents and watertight status. If it isn't watertight, what does that predict?

Hint
A non-watertight mesh has holes in the surface.
Show solution
A non-watertight mesh may slice with missing walls or odd gaps. Repair it in module 5 before printing.

Checkpoint quiz

Which format can reliably go back into CAD for dimensional edits?

STEP carries exact solid geometry; meshes do not.

STL files store…

STL is triangles only; the slicer assumes millimetres.

Best format for Bambu Studio projects with colours and settings?

3MF is a package that stores objects, colours and settings.

A 100 mm part imports as 3.94 mm. Likely cause?

100 mm ≈ 3.94 in; the slicer read 3.94 as millimetres.
